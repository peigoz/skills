# 文生图

一条命令生成图片并返回文件路径：

```bash
node scripts/generate.mjs "<中文提示词>"
```

脚本成功时把每张图保存到 `--out` 目录（默认 `./generated-images/`），路径逐行打印到 stdout。

## 厂商选择

`--provider openai|qwen`，或用环境变量 `T2I_PROVIDER` 常驻设置，缺省 `openai`。用户表达偏好（如"用通义/千问生成"）时传 `--provider qwen`；两边密钥都有而用户没说，就用默认值，不要反复追问。

| | openai | qwen（阿里云百炼） |
|---|---|---|
| 默认模型 | `gpt-image-2.5-sunburst` | `qwen-image-3.0`（另有 `qwen-image-3.0-pro`，`--model` 切换） |
| 密钥 | `OPENAI_API_KEY` | `DASHSCOPE_API_KEY` |
| 中转地址 | `OPENAI_BASE_URL` | `DASHSCOPE_BASE_URL`（模型/Key/URL 须同地域） |
| 格式 | webp（默认）/ png / jpeg | **仅 png** |
| `--quality` | 默认 `low` | 不支持，忽略 |
| `--n` 上限 | 10 | 6 |

## 选项

| 选项 | 默认值 | 说明 |
|---|---|---|
| `--size` | `1536x1024` | openai 只有三档（`1024x1024`/`1536x1024`/`1024x1536`/`auto`），脚本按形状就近映射；qwen 支持任意 WxH（总像素 512²~2048²，自动对齐到 16 倍数） |
| `--model` | 见上表 | API 报 model not found 时换成账户可用的型号 |
| `--format` | openai→webp，qwen→png | qwen 传其他格式会直接报错 |
| `--out` | `generated-images` | 交付给用户项目时指到项目的图片目录 |

## 工作流程

1. **确定用途和尺寸**：文章横幅/幻灯片封面用 `1536x1024`（默认），头像/图标/社交方图用 `1024x1024`，竖版海报用 `1024x1536`。用户没说就按用途推断，推断不了用默认值。
2. **用中文写提示词**。gpt-image 和 qwen-image 的中文理解都已足够好（qwen 本身是中文原生模型），不要翻译成英文；把用户的口语需求按下面的「提示词写法」整理成描述性中文短语即可。画面内要渲染的文字保持用户原文。
3. **用 Read 工具查看生成的图片**，确认与用户意图一致（主体、风格、文字有无乱码、手指等细节）后再交付。这一步不能省——把没验过的图直接甩给用户等于赌运气。
4. **报告保存路径**，简短说明生成内容与尺寸、用的哪家模型。
5. 不满意时**修改提示词再跑**，而不是原样重试：先想清楚偏在哪里（风格不对？构图太满？主体错了？），只调整对应的部分。

质量档位交给用户：默认 `--quality low`（仅 openai 生效），用户明确要求更高画质时才调整，不要自作主张升级。

## 提示词写法

按「主体 → 主体细节 → 场景 → 风格 → 光照 → 构图/质量」组织，用逗号分隔的短语，不必写完整句子：

```
湖边一座温馨的小木屋，屋顶覆着积雪，烟囱冒着炊烟，
扁平矢量插画风格，柔和马卡龙配色，广角构图，天空留白供后期压字
```

- **具体胜过抽象**："傍晚金色逆光" 比 "好看的打光" 可控得多。
- **给风格锚点**：扁平矢量插画 / 水彩 / 油画 / 3D 渲染皮克斯风 / 摄影 85mm 定焦 / 等距微缩 —— 风格词是对结果影响最大的一个成分，用户没指定时按用途选一个合理的并在交付时说明。个别模型对英文风格术语更敏感，中文描述明显跑偏时可只把风格词换成英文。
- **配图要留白**：为文章/PPT 做背景图时写明 "画面左侧/上方大面积留白，供叠加文字"，否则主体顶在中间没法压字。
- **画面内有文字**：用引号给出确切文本并说明位置（`画面顶部粗体大字"发布会"`)。gpt-image 和 qwen-image 对中文短标题渲染都不错，但字数越多越容易出错，生成后必须 Read 验图确认无乱码。
- **避免**：真实人物姓名与肖像、知名 IP 角色（会触发过滤或版权风险），被过滤时换成泛化描述。

## 故障处理

- 脚本失败时会把 HTTP 状态和 API 错误体打印到 stderr：401 是密钥无效，429 是配额/限流，400 多为参数或内容审核问题。
- `model not found`：默认型号可能未对该账户开放，用 `--model` 换成可用的（openai 侧如 `gpt-image-1`，qwen 侧 `qwen-image-3.0-pro`）。
- qwen 报地域错误：`DASHSCOPE_BASE_URL` 与 Key 的开通地域不一致，改为对应地域端点。
- 网络错误：Node fetch 不读 `HTTPS_PROXY`，需代理时设置对应的 `*_BASE_URL` 指向可直达的中转地址。
- 缺密钥：告诉用户需要创建并 export 哪个环境变量，不要自己编造密钥。
