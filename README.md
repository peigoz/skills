# Skills

个人 Agent Skills 集合，每个子目录是一个 skill（入口为 `SKILL.md`）。

## 列表

| Skill | 说明 |
| ------- | ------ |
| [frontend-design](frontend-design/SKILL.md) | 前端视觉设计指导（风格方向、排版、避免模板化） |
| [sigma](sigma/SKILL.md) | 1对1 AI 导师（Bloom 2-Sigma 掌握学习法） |
| [text-to-image](text-to-image/SKILL.md) | 文生图（OpenAI gpt-image / 阿里云百炼 Qwen-Image） |

## 使用

在支持 skills 的 Agent（如 Claude Code）中直接按名称调用，例如 `/text-to-image 生成一个风景画`；详细参数见各 skill 的 `SKILL.md`。
